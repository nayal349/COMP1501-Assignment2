Toy Store Company - Assignment 2 - group 5
================================

Course: COMP 1502
Project: Toy Store Company Inventory Management System
Authors: Mohamed El Hassen, Pushkar, Nathan

Description:
A Java console application for managing a toy store inventory. Users can search for toys by serial number, name, or type; purchase toys; add and remove toys; get gift suggestions; and save inventory changes.

Main class: mru.tsc.application.App
Inventory file: res/toys.txt

To run in Eclipse:
1. Import the Java project into Eclipse.
2. Ensure res/toys.txt is present in the project root's res folder.
3. Run mru.tsc.application.App as a Java Application.

Note: Inventory changes are written to res/toys.txt when Save & Exit is selected. Run the application with the project root as its working directory.

Documentation: doc/index.html (generated Javadoc)
Tests: JUnit tests in the project's test source folder
